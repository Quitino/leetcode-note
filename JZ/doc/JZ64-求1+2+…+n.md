求 1+2+...+n ，要求不能使用乘除法、for、while、if、else、switch、case等关键字及条件判断语句（A?B:C）。

 

示例 1：  
输入: n = 3  
输出: 6  


示例 2：  
输入: n = 9  
输出: 45  
 


```c
class Solution {
public:
    int sumNums(int n) {
        // return 0.5 * n * (n+1);

        // bool a[n][n+1];       // 数组size实现乘法
        // return sizeof(a)>>1;

        n > 1 && sumNums(n - 1); // 短路实现终止
        res_ += n;
        return res_;
    }

private:
 int res_ = 0;
};
```
